# Pawly — Árbol de navegación y wireframes

Reto 11 de ATI (2026-1), proyecto **Pawly** (red social de mascotas). Repositorio de trabajo del ejercicio: árbol de navegación por actor, arquitectura de información y wireframes de baja fidelidad, como borrador previo a Figma.

## Contenido

- `mapa_navegacion.puml` / `.png` / `.svg` — árbol de navegación por actor (Visitante, Usuario registrado, Administrador), a partir de los casos de uso y el Product Backlog del proyecto.
- `arquitectura_informacion.md` — tipos de página, unidades visuales, elementos individuales, patrones de navegación (índice, menú, visita guiada, consulta) e internacionalización.
- `wireframes/` — wireframes en HTML/CSS de baja fidelidad, mobile first (360×640) y desktop (1440×1024). Abrir `mobile.html` o `desktop.html` directamente en el navegador.

## Proyecto principal

El código y el resto de entregas de Pawly viven en la organización [Pawly-ATI-UCV](https://github.com/orgs/Pawly-ATI-UCV/repositories). Este repositorio es material de apoyo para el diseño de navegación e interfaz.
